# Main Color
- #FF4F81

| Attribute        | Value                                      |
| ---------------- | ------------------------------------------ |
| **Name**         | Warm Flamingo / Raspberry Pink             |
| **Hex Code**     | `#FF4F81`                                  |
| **Hue**          | Pink with slight red/magenta               |
| **Emotion**      | Love, passion, excitement, warmth          |
| **Gender Bias**  | Neutral (not overly feminine or masculine) |
| **Cultural Fit** | Romantic + youthful; great for matchmaking |
| **Contrast**     | Excellent on light and dark backgrounds ✅  |

## Why It’s a Good Pick for a Matrimony App
- Pros:
    - Feels romantic (key emotion for matrimony)
    - Modern and fresh, not boring
    - Less overused than Shaadi.com’s tone → makes your brand stand out
    - Works great with gold, cream, white, peach, and dark gray
    - Looks premium when paired with gradients or subtle textures

- Watch Out:
    - Avoid using it as full background — too strong
    - Best used as accent, CTA button, headers, and icons
